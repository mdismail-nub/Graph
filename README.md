# Graph

A beginner-friendly C++ repository covering **Graph Theory** from the basics to advanced algorithms. Whether you're preparing for **Competitive Programming**, **Coding Interviews**, or **University Exams**, this repository provides clean, well-commented implementations with simple explanations.

> 🚧 This repository is under active development. New topics and algorithms will be added regularly.

---

## 📚 Topics Covered

### ✅ Graph Representation
- Directed Graph
- Undirected Graph
- Weighted Directed Graph
- Weighted Undirected Graph
- Adjacency List
- Adjacency Matrix

### 🚀 Graph Traversal
- Breadth First Search (BFS)
- Depth First Search (DFS)

### 🌳 Trees
- DFS on Tree
- BFS on Tree
- Tree Diameter
- Lowest Common Ancestor (LCA)
- Binary Lifting

### 🛣️ Shortest Path Algorithms
- Dijkstra's Algorithm
- Bellman-Ford Algorithm
- Floyd-Warshall Algorithm
- 0-1 BFS

### 🌉 Minimum Spanning Tree
- Prim's Algorithm
- Kruskal's Algorithm
- Disjoint Set Union (DSU)

### 🔄 Topological Sorting
- Kahn's Algorithm
- DFS Based Topological Sort

### 🔁 Cycle Detection
- Directed Graph
- Undirected Graph

### 🧩 Connected Components
- DFS
- BFS
- DSU

### 🔍 Advanced Graph Algorithms
- Bipartite Graph
- Strongly Connected Components (Kosaraju)
- Bridges
- Articulation Points
- Euler Path & Circuit
- Hamiltonian Path
- Maximum Flow
- Minimum Cut
